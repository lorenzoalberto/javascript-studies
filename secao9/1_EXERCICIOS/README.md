# Exercícios — Seção 9

Esta sequência pratica ES Modules no Node.js. Cada exercício fica em seu próprio diretório porque a solução envolve dois ou mais arquivos.

Faça-os na ordem numérica. Leia o `README.md` do exercício, complete os trechos `TODO` e execute o `main.js`, por exemplo:

```bash
node 01_named_exports/main.js
```

O `package.json` deste diretório define `"type": "module"`, portanto use `import` e `export`, não `require`.

## Exercícios

1. Named exports
2. Default export
3. Alias de importação
4. Namespace com `import * as`
5. Barrel file e re-exports
6. Importação dinâmica
7. Catálogo modular — desafio final
