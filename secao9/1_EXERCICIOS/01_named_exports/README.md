# 01 — Named exports

No arquivo `operacoes.js`, exporte individualmente a constante `TAXA` com valor `0.1` e as funções `somar`, `subtrair` e `calcularComTaxa`.

`calcularComTaxa(valor)` deve devolver o valor acrescido de 10%. Em `main.js`, importe os quatro itens pelos nomes e exiba os resultados.

## Entrada

```js
somar(12, 8)
subtrair(12, 8)
calcularComTaxa(200)
```

## Saída esperada

```text
Soma: 20
Subtração: 4
Taxa: 0.1
Valor com taxa: 220
```
