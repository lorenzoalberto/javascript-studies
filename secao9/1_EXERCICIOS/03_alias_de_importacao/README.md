# 03 — Alias de importação

O arquivo `formatadores.js` deve fornecer três named exports: `paraMaiusculas`, `paraMinusculas` e `capitalizar`.

Em `main.js`, importe:

- `paraMaiusculas` com o alias `gritar`;
- `paraMinusculas` com o alias `sussurrar`;
- `capitalizar` sem alias.

`capitalizar` deve deixar a primeira letra maiúscula e as demais minúsculas.

## Entrada

```text
JavaScript Modular
```

## Saída esperada

```text
JAVASCRIPT MODULAR
javascript modular
Javascript modular
```
