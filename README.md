# JavaScript Studies

Repositório dedicado aos meus estudos de **JavaScript**, contendo anotações, exercícios, exemplos e experimentos desenvolvidos durante meu aprendizado.

## Objetivo

Este repositório tem como objetivo registrar e organizar minha evolução no estudo de JavaScript, servindo como material de consulta e espaço para prática dos conceitos aprendidos.

O conteúdo pode incluir desde fundamentos da linguagem até conceitos mais avançados, conforme avanço nos estudos.

## Curso

Atualmente, estou utilizando como principal material de estudo o curso **Curso de JavaScript e TypeScript do básico ao avançado**, disponível na Udemy.

O repositório não representa ou reproduz oficialmente o conteúdo do curso. Os códigos, anotações e experimentos aqui presentes fazem parte do meu processo pessoal de aprendizado e prática.

## Observações

Este é um repositório de **estudo pessoal**. Alguns códigos podem ser propositalmente simples, experimentais ou apresentar diferentes abordagens para o mesmo problema, já que o objetivo principal é explorar e compreender os conceitos da linguagem.
