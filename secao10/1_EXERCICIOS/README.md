# Exercícios — Seção 10

Faça os exercícios na ordem numérica. Cada diretório contém um `README.md` com o enunciado e arquivos iniciais com trechos `TODO`.

## Conteúdo

1. Relatório recursivo de arquivos com `fs` e `path`
2. Persistência de tarefas em JSON
3. Primeira API com Express
4. API usando `req.params`, `req.query` e `req.body`
5. Separação entre rotas e controllers
6. Middleware de autenticação
7. Helmet, sessão e proteção CSRF

Nos exercícios de Express, entre no diretório correspondente e execute `npm install` antes de iniciar o servidor com `npm start`.
